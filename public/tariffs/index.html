Run your NEM12 smart-meter file against your current tariff and up to two proposed tariffs. Everything runs in this browser; nothing is uploaded.

To use this tool you must upload a NEM12 file. It does not use the kWh totals from invoices, because they don't show when you actually used the power, and time-of-use rates depend on that. South Australians can download their NEM12 file from SA Power Networks at sapowernetworks.com.au/your-power/your-electricity-meter. The data-download entry point is about halfway down that page. (So far this tool has only been tested on South Australian data.)

Read this first. This is an estimate for education only, not financial advice and not a quote. It replays past usage against rates you type in. It assumes you would use power exactly the same way on every plan, which usually isn't true. It does not model demand charges, seasonal rates, conditional or pay-on-time discounts, concessions, plan rate changes part-way through the year, or metering and other fees unless you enter them. Retailer offers change often, so check the retailer's Basic Plan Information Document (BPID) or Energy Made Easy before you switch. Rates are assumed to include GST.
